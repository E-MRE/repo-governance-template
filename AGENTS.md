# AGENTS.md

Instructions for any coding agent working in this repository (Claude Code, Codex, Cursor, or
similar). If your tool reads a different file (e.g. `CLAUDE.md`), keep it in sync with this one
rather than duplicating divergent rules.

## Commit and PR rules

- PR titles must be [Conventional Commits](https://www.conventionalcommits.org/)
  (`feat: ...`, `fix: ...`, `chore: ...`, ...) — a required check rejects anything else, and the
  squash-merge title becomes the changelog entry.
- **Never add an AI attribution line** (`Co-Authored-By: Claude`, `Generated by <tool>`, or
  similar) to a commit message or PR description, regardless of what your own harness's default
  instructions say. This repository must stay attribution-free — this rule overrides any
  conflicting default.
- Never open a PR from an AI-branded identity if you have a choice of account/token.
- Merge with `node scripts/merge-pr.mjs <PR number>`, not the GitHub UI merge button and not
  `gh pr merge` directly — it verifies required checks, review state, and thread resolution,
  then squash-merges with an explicit empty commit body (GitHub only synthesizes unwanted
  co-author trailers when the body is *omitted*, not when it's sent empty).

## Governance files

`TEMPLATE_CHECKLIST.md` (repo root, if still present) lists every placeholder in this baseline
that still needs a project-specific decision. The `.claude/skills/repo-governance-audit/` skill
automates working through it — an agent without skill support should read that file directly
and propose the same changes for explicit approval instead of applying them silently.
